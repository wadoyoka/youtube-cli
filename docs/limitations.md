# 既知の制約

- **クォータ。** 動画のアップロード（`videos.insert`）は、プロジェクトごとに 1 日 100 本まで。使い切ると終了コード 8 で止まり、太平洋時間の 0 時に戻る。ほかの操作も 1 日のクォータを使う。
- **サムネイルには電話番号の確認が要る。** カスタムサムネイルを設定するには、YouTube のチャンネルが電話番号で確認されている必要がある。確認されていないと、`thumbnail` や `upload --thumbnail` のサムネイルの手順が失敗する（動画自体は上がる）。画像は jpg か png で 2 MiB まで。
- **OAuth スコープが広い。** スコープは `https://www.googleapis.com/auth/youtube.force-ssl` だけだが、これは YouTube の管理に近い広い権限で、トークンが漏れると、Google 側の API では動画の削除や公開範囲の変更もできてしまう。youtube-cli にはそうした操作がなく、削除・更新・公開範囲の変更の API を呼ぶコードは、archtest が書けないようにしている。ただし、**スコープそのものが守っているわけではない。** 守りは次の 3 つ。
  - トークンと client_secret を暗号化して保存し、鍵を OS のキーチェーン（または `key` のファイル）に分けて置く。
  - 設定ディレクトリ（`token.enc`、`key` など）を、AI エージェントや他人に渡さない。
  - 万一漏れたら、Google アカウントの「サードパーティのアクセス」から取り消し、`youtube-cli logout` と `login` をやり直す。
- OAuth 同意画面の公開ステータスを「テスト」で運用するので、ログインは 7日で切れる。切れたら `youtube-cli login` をやり直す。ログインできるのは、テストユーザーに入れた Google アカウント（最大 100 人）だけ。
- **一覧は上げた直後に遅れることがある。** YouTube の一覧 API は、上げたばかりの動画を返すのが遅れる。そのため `ls` と同じタイトルの確かめは、この PC の手元の記録（設定ディレクトリの `ledger.json`）の動画 ID を足して引く。この助けは**この PC だけ**。**ほかの PC で上げた直後の動画は、`ls` に遅れて出る**ことがあり、同じタイトルの確かめもすり抜けることがある（二重に上げうる）。複数の PC から続けて同じタイトルを上げないこと。
- 手元の記録にあって YouTube で見つからない動画（Studio で消した動画など）は、`ls` に出ない。
- **別のチャンネルを選んだログインは止まる。** 2回目以降のログインで、保存してあるチャンネルと違うチャンネルを選ぶと、終了コード 5 で止まる。切り替えるときは `login --switch-channel`（手元の記録 `ledger.json` を消す）。
- **上げた動画を、このツールは消せない。** 削除する機能がない。失敗・却下の状態の動画や、試しに上げた動画は、YouTube Studio で消す。
- **結果が分からないアップロードは、自動では送り直さない。** 二重に上げないため。Studio で確かめてから `--skip-existing` で続ける。
- 16 MiB より小さい動画は 1 回の要求で送る。それ以上は分けて送る（再開可能アップロード）。送り始めたあとに止められたアップロードを、次の実行で途中から再開することはできない。
- 同じタイトルの動画は、このツールでは上げられない（`--skip-existing` で既存のものを使う）。タイトルを変えて上げる。
- 目印のタグ `youtube-cli` を Studio で消した動画は、`ls` などで見えなくなる。再生リストの説明の最後の行 `[youtube-cli]` を消したものも同じ。
- 拒否リスト（`policy.toml`）は誤操作を防ぐための柵で、設定ディレクトリに書き込めるもの（AI エージェントを含む）なら書き換えられる。セキュリティの境界ではない。
- **同時実行について。** 同じ PC の中では、手元の記録（`ledger.json`）への書き込みをロックファイルで 1 つずつ順番に行う。同じタイトルを同時に 2 つ上げる競合までは防がない。複数の PC から同時に使わないこと。
- **Windows について。**
  - 鍵は資格情報マネージャーに置く。同じユーザーのどのプログラムからも読めるので、守りの水準は Linux と同じで、macOS より低い。
  - `agents/setup.sh` は Windows に対応していない。

## 作らないもの（v1）

動画の削除・更新・公開範囲の変更、限定公開以外（公開・非公開）でのアップロード、動画や再生リストの並べ替え・削除、このツールで上げていない動画の操作、ライブ配信、コメント、字幕、予約公開、サービスアカウント、Workspace、途中で止まったアップロードの再開、配布用パッケージ。
