# youtube-cli ― YouTube へ限定公開で動画を上げる

`youtube-cli` は、自分の YouTube チャンネルへ動画を **限定公開（unlisted）だけ** で上げる CLI。公開や非公開では上げられず、
動画の削除・更新・公開範囲の変更の機能もない。対象は、タグ `youtube-cli` を付けてこのツールで上げた動画と、
このツールで作った再生リストだけ。**二重に上げる・人が決めることを勝手に進める** ことは起こりうるので、下の手順と決まりを守る。

## 手順

### 1. 使える状態かを確かめる

```bash
command -v youtube-cli
youtube-cli status --json
```

- `youtube-cli` が見つからなければ止まり、人にインストールを頼む（リポジトリの README に手順がある）。
- `status --json` の `loggedIn` が `true` なら次へ進む。
- **終了コード 3**（`loggedIn` が `false`、鍵がない、キーチェーンが使えないなど）なら **止まって人に戻す**。
  「`youtube-cli setup`（初回）か `youtube-cli login` が必要です」と、`problem` やエラーの `message` を添えて伝える。
  自分で `setup`・`login`・`init` を実行しない。
  ログインは 7日で切れる（OAuth 同意画面を「テスト」で運用しているため）。前に使えていたのに終了コード 3 になったときは、
  「ログインの期限が切れたようです。`youtube-cli login` を実行してください」と伝える。
- **終了コード 7**（拒否リストで止められた）なら止まって人に伝える。`policy.toml` を書き換えたり、回避したりしない。
- **終了コード 8**（クォータを使い切った。動画は 1 日 100 本まで）なら止まって人に伝える。太平洋時間の 0 時（日本時間の 16 時か 17 時）に戻る。やり直さない。

### 2. タイトルを決める

形式は `【動画シリーズ名】#.{No} 動画タイトル`（例: `【Go入門】#.3 エラー処理`）。

- 動画シリーズ名と動画タイトルは、人の依頼から決める。分からなければ人に聞く。
- **No は、そのシリーズの既存の最大の No + 1。** `youtube-cli ls --json` の `title` から、同じ `【動画シリーズ名】` で始まるものの `#.` のあとの数字を読み、最大を取って 1 を足す。
  そのシリーズの動画がまだなければ 1 から始める。桁はそろえない（`#.03` ではなく `#.3`）。
- 人が No を指定したときは、その番号を使う。ただし `ls --json` に同じ番号があれば、人に確かめる。
- タイトル全体は 100 文字以内。`<` と `>` は使えない。長ければ、動画タイトルを縮める。
- `ls` に出るのは、このツールで上げた動画だけ。ブラウザや Studio から入れた動画の No は見えない。
  また、**ほかの PC で上げた直後の動画は、`ls` に遅れて出る**ことがある（この PC で上げたものはすぐ出る）。心当たりがあれば、人に確かめる。

### 3. アップロードする

```bash
youtube-cli upload --json --title "【Go入門】#.3 エラー処理" --description-file ./desc.txt ./video.mp4
youtube-cli upload --json --title "【Go入門】#.3 エラー処理" --thumbnail ./thumb.png --playlist "Go入門" ./video.mp4
```

- 公開範囲は常に限定公開。変えられない。
- 説明が長いときは `--description-file`（`--description` とは同時に使えない）。タグは `--tag` を繰り返す。
- `--thumbnail` は jpg か png で 2 MiB まで。チャンネルの電話番号の確認が要る。
- `--synthetic-media` は、**本物と見分けがつかない、人物や出来事の合成・改変のコンテンツのときだけ**付ける（YouTube の「改変または合成されたコンテンツ」の申告）。
  普通の解説動画、画面録画、アニメーション、明らかな CG には付けない。迷ったら人に聞く。
- `--made-for-kids` は、人が子ども向けと言ったときだけ付ける。
- **大きい動画（目安 100 MB 以上）はバックグラウンドで実行する。** コマンドの実行時間の上限（Claude Code の Bash ツールは既定 2 分、最大 10 分）で止められると、
  動画ができたか分からなくなる。Claude Code なら `run_in_background` を使う。

#### 再生リスト

- 再生リストの名前は、**動画シリーズ名**にする（例: `Go入門`。`【】` は付けない）。
- 再生リストは、人が拒否リストから `playlist-create` と `playlist-add` を外したときだけ使える。既定では止まっている。
- 使うとき: `youtube-cli playlist ls --json` で、シリーズ名の再生リストがあるかを見る。なければ `youtube-cli playlist create "<シリーズ名>"` で作ってから、`upload --playlist "<シリーズ名>"` で上げる。
- **`playlist create`・`playlist add` が終了コード 7 になったら、再生リストの操作をやめて、人に伝える。**
- **`upload --playlist` が終了コード 7 のときは、何も上がっていない**（上げる前に拒否リストを確かめるため）。`--playlist` を外して上げ直し、再生リストには入れていないことを人に伝える。
  `upload` 自体が拒否されているときも 7 になる。`--playlist` を外しても 7 なら、止まって人に伝える。
- 人が拒否リストを外したあとで、`youtube-cli playlist add <動画 ID> "<シリーズ名>"` で動画を入れられる。

### 4. 結果を確かめる

成功・失敗は、**終了コードと JSON の両方**で判断する。

- 終了コード 0: 成功。標準出力の JSON に `videoId`・`url`・`studioUrl`・`privacyStatus`（`unlisted`）が入る。`warnings` があれば人に伝える。`privacyStatus` が `unlisted` でなければ、Studio で確かめるよう人に伝える。
- 終了コード 1: 次の 2 つがある。
  - **「アップロードの結果が分かりません」。止まって人に伝える。** 動画ができているかもしれない。自分で送り直さない。人に YouTube Studio で確かめてもらい、そのあとで同じコマンドに `--skip-existing` を付けてやり直す。
  - 動画はできたが、サムネイルか再生リストの追加が失敗した（標準出力に JSON、標準エラーにエラーが出る）。`thumbnail.done` と `playlist.done` を見て、失敗した手順を人に伝え、同じコマンドに `--skip-existing` を付けてやり直す（上げずに、残りの手順だけを行う）。
- 終了コード 5（衝突）: 次のどちらか。
  - 同じタイトルの動画がすでにある。何も上げられていない。タイトルの No を確かめ直す。前の実行が途中までできていたなら、`--skip-existing` を付けて続ける。タイトルが違う動画なのに衝突したときは、勝手に `--skip-existing` を付けない。
  - **既存の動画が失敗・却下・削除の状態（「使えない状態」）。止まって人に伝える。** youtube-cli には削除がないので、人が Studio でその動画を消す。`--skip-existing` を付けても通らない。
- 終了コード 2（引数の誤り）: コマンドを直す（タイトルが 100 文字を超えている、サムネイルの形式が違うなど）。
- 終了コード 4: 手元のファイル、動画 ID、再生リストが見つからない。パスや名前を確かめる。
- 終了コード 6: 同じ名前の再生リストが複数ある。候補の ID と URL を人に見せて、判断を仰ぐ。推測で選ばない。

### 5. 人に伝える

動画の `url`（`https://youtu.be/...`）と `studioUrl` を伝える。限定公開なので、リンクを知っている人だけが見られること、
上げた直後は YouTube の処理が終わるまで再生できないことがあることを、一言添える。

## 決まり

- **作業の前に `status --json`。** 終了コード 3・7・8 では止まって人に戻す。
- **`--json` を付ける。** 成功時は標準出力に結果の JSON が 1 つ、失敗時は標準エラーに `{"error":{"kind":...,"message":...,"details":[...]}}` が出る。
- **`setup`・`login`・`logout`・`init` は実行しない。** ブラウザでの操作が要る、GCP を変える、ログインを消すなど、人が行う操作のため。
- **二重に上げない。** 結果が分からないときは送り直さず、人に Studio で確かめてもらう。やり直しは `--skip-existing`。
- **勝手に `--skip-existing` を付けない。** 同じタイトルが衝突したときに付けると、新しい動画が上がらず、前の動画が使われる。付けるのは、前の実行が途中まで進んだことが分かっているときだけ。
- 設定ディレクトリ（`~/.config/youtube-cli/`、Windows では `%LOCALAPPDATA%\youtube-cli\` など）のファイル、`security` コマンドには触れない。Windows では `cmdkey` と資格情報マネージャーにも触れない。
  OAuth のスコープ（`youtube.force-ssl`）は広く、トークンが漏れると動画の削除などもできてしまうため。
